La ruta de creación ya gestionaba correctamente errores de `pthread_create` y no se modificó. |

## Límites que no deben ocultarse

- `flutter analyze`, `flutter test` y el build Android necesitan evidencia nueva de Codemagic. El entorno local no dispone de Flutter, Dart, Java ni Android SDK.
- GitHub Actions está deshabilitado a nivel de repositorio; no se pudo despachar `flutter-quality.yml` ni el workflow Android.
- La descarga real del dataset no pudo ejecutarse en este sandbox porque solo permite hosts de GitHub y bloquea `raw.githubusercontent.com` y `downloads.majestic.com`. No se usó el fallback semilla para inventar métricas holdout.
- No se ejecutó una VPN en hardware físico. Permisos, cortes de red, roaming, reinicio, bloqueo de apps, consumo y compatibilidad OEM requieren pruebas en dispositivos.
- La compilación DEBUG explícita de Codemagic no valida firma de producción. Una distribución real exige keystore y secretos de producción configurados y verificación del certificado del artefacto.
